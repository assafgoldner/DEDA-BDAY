# בבה ודדה — אתר זיכרון משפחתי

אתר לזכרם של **מיה וליאו גולדנר**. אתר סטטי אחד — בלי שרת, בלי מסד נתונים
ובלי תלויות חיצוניות. נפתח גם בלחיצה כפולה על `index.html`.

## מה יש כאן

| קובץ / תיקייה | מה זה |
|---|---|
| `index.html` | **כל האתר** — HTML, CSS, JS וכל התוכן בקובץ אחד |
| `images/` | 99 תמונות ארכיון, ממוספרות לפי סדר כרונולוגי (001 = המוקדמת) |
| `recipes/` | 10 סריקות של מתכונים בכתב יד, אחרי שיפור קריאוּת |
| `icons/` | אייקוני האפליקציה |
| `images.json` | מניפסט התמונות: קובץ, כיתוב, תקופה, שנה, סיפור מקושר |
| `manifest.webmanifest`, `sw.js` | מה שהופך את האתר לאפליקציה שניתן להתקין |
| `render.yaml` | הגדרות הפריסה ב-Render |
| `content.py` | סיפורים, רגעים, כיתובי תמונות, שנים |
| `content2.py` | טריוויה, קורות החיים של ליאו, תמלול המתכונים |
| `content3.py` | ציר הזמן, המקומות, הקישורים, עץ המשפחה |
| `קורות-חיים-ליאו-גולדנר.txt` | המסמך המקורי |

> קבצי ה-`content*.py` הם **מקור הידע**, לא קוד שרץ באתר. התוכן כבר מוטמע
> בתוך `index.html`; הם נשמרים כאן כדי שיהיה נוח לערוך ולבנות מחדש.

## התקנה כאפליקציה

אחרי שהאתר באוויר (ראו "פריסה" למטה) אפשר להתקין אותו כאפליקציה אמיתית:

- **אייפון / אייפד** — לפתוח ב-Safari, ללחוץ על כפתור השיתוף, ואז **"הוסף למסך הבית"**.
- **אנדרואיד** — לפתוח ב-Chrome, ואז התפריט ⋮ ← **"התקן אפליקציה"**.
- **מחשב (Chrome / Edge)** — יופיע אייקון התקנה בשורת הכתובת, או כפתור
  "התקנה כאפליקציה" בפינה השמאלית התחתונה.

אחרי ההתקנה האתר נפתח בחלון משלו, בלי שורת כתובת, ועובד גם בלי אינטרנט.

**שימו לב:** התקנה עובדת רק מכתובת `https://` — לא מקובץ מקומי.

## פריסה ב-Render

### שלב 1 — להעלות לגיטהאב

```bash
cd "בבה-ודדה-אתר"
git init
git add .
git commit -m "אתר הזיכרון של בבה ודדה"
git branch -M main
git remote add origin https://github.com/<השם-שלך>/baba-dede.git
git push -u origin main
```

אם אין עדיין ריפו — ליצור אחד ריק ב-https://github.com/new
(בלי README ובלי .gitignore — הם כבר כאן).

**פרטי או ציבורי?** בריפו פרטי התמונות לא גלויות לאיש, ו-Render יודע לפרוס
ממנו גם בתוכנית החינמית. זו הבחירה המומלצת כאן.

### שלב 2 — לחבר ל-Render

1. להיכנס ל-https://dashboard.render.com ולהתחבר עם חשבון GitHub.
2. **New +** ← **Static Site**.
3. לבחור את הריפו.
4. למלא:
   - **Name**: `baba-dede`
   - **Branch**: `main`
   - **Build Command**: *להשאיר ריק*
   - **Publish Directory**: `.`
5. **Create Static Site**.

הקובץ `render.yaml` כבר מגדיר את כל זה, כך שאם Render מזהה אותו אפשר פשוט
לאשר את מה שהוא מציע.

תוך דקה-שתיים האתר יהיה באוויר בכתובת `https://baba-dede.onrender.com`.
אתר סטטי ב-Render הוא בחינם, בלי הגבלת זמן ובלי "הירדמות" של השרת.

### שלב 3 — דומיין משלכם (לא חובה)

ב-Render: **Settings → Custom Domains → Add Custom Domain**, ואז להוסיף אצל
ספק הדומיין רשומת `CNAME` לכתובת ש-Render נותן.

### עדכונים

כל `git push` ל-`main` מפרסם מחדש אוטומטית. אין צורך לעשות דבר ב-Render.

## עריכת תוכן

הכול יושב במערכים בתוך תגית ה-`<script>` שב-`index.html`:

| מערך | מה הוא מכיל |
|---|---|
| `ARCHIVE` | התמונות: `{src, cap, era, year, story}` — הסדר במערך הוא הסדר באתר |
| `STORIES` | הסיפורים: `{era, title, body:[פסקאות], src}` |
| `MEMOS` | הרגעים הקצרים |
| `TRIVIA` | השאלות: `{cat, q, a, s, o:[3 מסיחים], note}` |
| `CV` | קורות החיים: `{stats, path, projects, note}` |
| `RECIPES` | המתכונים: `{t, by, date, img, ing, steps, note}` |
| `TIMELINE` | ציר הזמן: `{y, t, d, k}` — `k` הוא `life` / `work` / `home` |
| `PLACES` | `{il:[...], world:[...]}`, כל מקום עם `ll:[רוחב, אורך]` |
| `WEBLINKS` | הקישורים |
| `FAMILY` | עץ המשפחה לפי דורות |

להוספת תמונה: לשים קובץ ב-`images/` ולהוסיף רשומה ל-`ARCHIVE` במקום הנכון בסדר.

אחרי כל שינוי כדאי להעלות את מספר הגרסה ב-`sw.js`
(השורה `const CACHE = 'baba-dede-v1'`) כדי שהדפדפנים של המשפחה יקבלו את
הגרסה החדשה ולא את זו ששמורה אצלם.

## מה המשפחה יכולה להוסיף דרך האתר

סיפורים, תמונות, מסמכים, מתכונים, קישורים, שאלות ושמות בלוח החופשי.

**חשוב:** כל זה נשמר בדפדפן המקומי של מי שהוסיף, ולא עולה לאתר עצמו.
בלשונית "שמירה" יש ייצוא וייבוא של קובץ גיבוי — כך אפשר לשלוח תוספות
ולהכניס אותן פנימה.

למעבר לשיתוף אמיתי בזמן אמת, שבו כולם רואים הכול מיד, צריך שכבת ענן (Firebase).
